# Contributing

Thanks for your interest in Model Recommender. Open an issue to discuss a larger change before starting work. Small fixes can go straight to a pull request.

Keep changes focused and preserve the manual settings choice, local offline inference, and the original request when the hook pauses a prompt. Update the README when a change affects installation, use, configuration, or troubleshooting.

In your pull request, describe the user-visible change and the checks you ran. Do not include local runtime files, downloaded models, or personal machine metadata.
